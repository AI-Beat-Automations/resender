React + Tailwind — pegar en Lovable

Autocontenido: sin imports del monorepo, sin cn(), sin tokens del design system. Los colores van literales para que funcione en cualquier proyecto.

export function GridBackground({
  size = 40,
  fill = "rgba(36, 32, 41, 0.1)",
  fade = true,
}: {
  size?: number
  fill?: string
  fade?: boolean
}) {
  return (
    <div
      aria-hidden
      className="pointer-events-none fixed inset-0 -z-10 size-full"
      style={{
        backgroundColor: "#f3ede1",
        backgroundImage: [
          `linear-gradient(to right, ${fill} 1px, transparent 1px)`,
          `linear-gradient(to bottom, ${fill} 1px, transparent 1px)`,
        ].join(", "),
        backgroundSize: `${size}px ${size}px`,
        maskImage: fade
          ? "radial-gradient(ellipse at center, #f3ede1, transparent)"
          : undefined,
      }}
    />
  )
}

Cómo reconstruirlo a mano en Figma

  • Frame con fill #F3EDE1.
  • Línea vertical de 1px, fill #DED9CF, alto = alto del frame. Duplicar con ⌘D y separación de 40px (o usar Auto Layout horizontal con gap 39).
  • Repetir en horizontal y agrupar todo como grid/40.
  • El fade de bordes: elipse centrada, fill radial #F3EDE1 → transparente, aplicada como mask sobre el grupo (o simplemente bajar el grupo a ~40% de opacidad si no querés máscara).
  • Importando este HTML con html.to.design, las máscaras CSS pueden no viajar: si el grid llega plano, aplicá el fade a mano con el paso anterior.
